All Servus commands live under one root, `/servus`, with a branch per mod: `/servus foundation`, `/servus shuttles` and `/servus alchemy`.
Most of them need operator permission and work over RCON and from the server console.

This page is generated from the command catalog each mod ships in the [Edict](https://edict.leberkas.org/spec) format, as it is in the latest release of that mod.
