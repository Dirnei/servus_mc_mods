## What you need

All Servus mods run on **Minecraft 26.1.2** with **NeoForge 26.1.2.116** or newer. Put the jars into your `mods` folder.

| Mod | Version | Needs |
|---|---|---|
| Servus: Foundation | 0.4.0 | nothing else |
| Servus: Shuttles | 0.4.0 | Servus: Foundation 0.4.0 or newer |
| Servus: Alchemy | 0.3.0-alpha | Servus: Foundation 0.4.0 or newer, and Modonomicon |

Shuttles and Alchemy do not need each other. They work alone and together. JEI is optional; with it installed the Servus recipes show up there. Jade is optional too and shows the state of the Alchemy machines.

:::caution[Alchemy is an alpha]
Servus: Alchemy is still an alpha. Builds can change between versions, and a few journal pages are placeholders. Back up your world before you update it.
:::

## Two tools first

Every Servus mod uses the same two tools from Foundation:

- **Configuration Carrot**: the wrench. Use it on a face of a machine to change that side, and sneak use it to pick up a block with its settings. On a duct it opens the duct's side settings.
- **Engineer Goggles**: wear them to see hidden things, such as side settings and ducts behind facades.

## Your first base

1. **Power.** Craft a Coal Generator. It burns any furnace fuel into FE and feeds machines that touch it.
2. **Pipes.** Craft Item Pipes, Power Cables or Fluid Pipes. Each one places a Utility Duct, or adds its line to a duct that is already there. One duct can carry all of them.
3. **Water.** Put a Burner Pump on an infinite water source and pipe the water where you need it. Store fluids in Fluid Tanks.
4. **Trash.** Build a Sink (eight Sink blocks in a cube) to void what you do not need.

From here, pick where you want to go:

- Build a warehouse with [Servus: Shuttles](/servus_mc_mods/mods/shuttles/). Start with a Heavy Duty Rack, a Warehouse Rail, a Shuttle Garage with a shuttle and a Warehouse Controller.
- Start the alchemy of [Servus: Alchemy](/servus_mc_mods/mods/alchemy/). Read Paracelsus' Journal, which you get at your first login, and build the Calciner.

## Modpacks

Balance numbers and recipes live in datapack JSON, so a modpack may have changed the numbers on these pages. See the [datapack reference](/servus_mc_mods/reference/datapack/machines/).
