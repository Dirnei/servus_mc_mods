## Built for modpacks

Recipes, techs, deposits and machine balance numbers live in datapack JSON. The [datapack reference](/servus_mc_mods/reference/datapack/machines/) lists every field, and the [Balance lab](/servus_mc_mods/lab/) lets you try new numbers before you ship them.
