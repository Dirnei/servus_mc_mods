## For modpacks

Recipes and balance numbers live in datapack JSON. The [datapack reference](/servus_mc_mods/reference/datapack/machines/) lists the formats and the shipped values.

## For mod developers

Machines of other mods can join the Servus data line, so a Shuttles warehouse can stock them and its Crafting CPU can order from them. The [developer guide](/servus_mc_mods/developers/) shows how, and the Machine Adapter covers machines whose mod does nothing.
