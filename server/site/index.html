Version {{VERSION}} · Minecraft {{MC}} with NeoForge {{NEO}}

1. Set up the game in the FTB App

Download pack for the FTB App
  1. Open the FTB App and click Create Instance.
  2. Choose Curse Import and pick the file you just downloaded.
  3. Wait until the instance appears in your library.
The import fails or nothing happens?

Set it up by hand instead. This always works.

Download mods only
  1. Create Instance, Vanilla, pick Minecraft {{MC}} and the mod loader NeoForge {{NEO}}.
  2. Open the instance's folder (the folder icon in the instance view).
  3. Unpack everything from the downloaded zip into the mods folder there.
Using Prism Launcher or the Modrinth App? Download .mrpack

Add Instance, Import, pick the .mrpack.

2. Give it enough memory

In the instance settings, set the memory (RAM) to 4 GB or more.

3. Join the server

  1. Start the instance and choose Multiplayer, Add Server.
  2. Use this server address:
    this-computer

When there is a new version

Come back here, download mods only, empty the instance's mods folder and unpack the new zip into it. The world lives on the server, so nothing is lost.

If the game says the mods do not match the server, you have an old version.
