# Spec Delta

## MODIFIED Requirements

### Requirement: Access Point is obtainable
The Access Point SHALL be crafted from iron ingots, a chest, redstone, copper and planks (example), recording the wood of the planks, drop itself with its wood and the contents of both buffers when broken, and be dismantled by sneaking with the Configuration Carrot.

#### Scenario: Broken with items
- **WHEN** an Access Point holding planks in its outgoing buffer is broken
- **THEN** the Access Point and the planks drop
